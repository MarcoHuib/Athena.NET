# Athena.NET GitHub Pages package

Built from:
- Repository: https://github.com/MarcoHuib/Athena.NET
- Branch: `feature/poring-live-wire`
- Snapshot commit: `a7513e2defa2347d5ba20ff501436258d8503d04`
- Custom domain included: `athenanet.nl`

## Upload

Upload the **contents of this folder** to the branch/folder used by GitHub Pages.
The root must contain `index.html`, `docs.html`, `CNAME`, `.nojekyll`, `robots.txt`, and `sitemap.xml`.

Recommended GitHub Pages setting:
- Source: Deploy from a branch
- Branch: your Pages branch, root `/`

The documentation reader deliberately loads Markdown from the pinned Git commit above. This means the site remains tied to the exact repository snapshot it was generated from while still keeping the upload small.

## DNS

The included `CNAME` expects `athenanet.nl`. Remove or edit that file if you deploy under a different domain.

## Google

After the domain resolves:
1. Verify the domain property in Google Search Console using your DNS TXT record.
2. Submit `https://athenanet.nl/sitemap.xml`.
3. Request indexing for the homepage and documentation index.

## Updating later

Regenerate this site against a newer commit when the public docs/status materially change.
