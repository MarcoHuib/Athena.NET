Why Athena.NET

Old world. New foundation.

Athena.NET is not a port of rAthena. Mature projects are used as behavioral and research references while protocol handling, gameplay, persistence, world data and infrastructure are implemented as a new modern stack.

◎

Official iRO first

Compatibility work targets the current official International Ragnarok Online client instead of generic kRO compatibility.

⌁

Evidence-driven

Verified captures and proven runtime behavior take precedence over assumptions or copied packet tables.

</>

Modern .NET

Current C#, async I/O, dependency injection, strongly typed domain code and automated tests.

◇

Clean boundaries

Protocol, gameplay, persistence, world data and infrastructure can evolve independently.

Project status

A playable early-game vertical slice.

The stock client can already treat Athena.NET like a real server across login, character selection, world entry and a focused slice of gameplay. It is still active development, not a production public-server release.
